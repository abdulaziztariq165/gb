# Dev Display Helper

تطبيق أندرويد للمطورين لتحسين أداء وعرض الشاشة. يعمل عبر **Shizuku** (صلاحيات ADB) ولا يحتاج روت.

## الميزات
- رفع معدل التحديث إلى أقصى ما تدعمه الشاشة، وزر تثبيت الإطارات
- عرض معدل التحديث الحي (حجم / شفافية / مكان قابل للتحكم)
- 15 تعديلاً يدوياً لألوان الشاشة + أنماط جاهزة: حيوي، واقعي، سينما، HDR
- دقة Full HD / 2K / 4K ونسبة مخصصة مع الحفاظ على نسبة الأبعاد (بدون حواف سوداء)
- دائرة بصرية حمراء/خضراء في منتصف الشاشة (حجم وشفافية)
- زر عائم قابل للسحب مع لوحة إعدادات سريعة

## البناء
1. ارفع المجلد إلى مستودع GitHub جديد.
2. من تبويب **Actions** شغّل **Build APK**، ثم حمّل الـ APK من Artifacts.
(أو محلياً: `gradle assembleDebug` مع JDK 17.)

## التشغيل
1. ثبّت Shizuku وشغّله (Wireless debugging أو ADB).
2. افتح التطبيق ← **طلب صلاحية Shizuku** ← **السماح بالعرض فوق التطبيقات**.

## ملاحظات
- تعمل الألوان عبر `SurfaceFlinger 1015` وقد لا تدعمها بعض الأجهزة/الإصدارات. الحدة (Sharpness) غير ممكنة بهذه الطريقة.
- عداد FPS يقيس معدل إطارات النظام، وليس FPS داخل لعبة معينة.
- `wm size` قد يؤثر على الواجهة؛ استخدم "إعادة الدقة الأصلية" عند الحاجة.
- بعض الألعاب تمنع أي Overlay فوقها.
